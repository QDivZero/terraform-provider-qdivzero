# QDivZero Provider

Use the QDivZero provider to manage inference instances, schedules, vector
databases, target groups, and Smart Balancers. Discover GPU options and existing
serving endpoints with data sources. See the repository [README](../README.md)
for installation and configuration.

## Provider attributes

| Attribute | Description |
| --- | --- |
| `api_key` | Sensitive API key; defaults to `QDIVZERO_API_KEY`. |
| `api_url` | API base URL; defaults to `QDIVZERO_API_URL` or `https://api.qdiv0.com`. |
| `account_id` | Optional account ID; defaults to `QDIVZERO_ACCOUNT_ID`. |
| `private_beta_token` | Sensitive optional beta token; defaults to `QDIVZERO_PRIVATE_BETA_TOKEN`. |
